# HTML to PDF Conversion Service

This is a simple and robust microservice for converting HTML content to PDF files. It is built with Python using the Flask framework and leverages `wkhtmltopdf` for high-quality PDF rendering. The service is containerized with Docker for easy deployment and scalability.

## Features

- **HTML to PDF Conversion**: Convert raw HTML strings into PDF documents.
- **Zip Archive Support**: Accepts a `.zip` file containing multiple HTML files and returns a `.zip` file with the corresponding PDFs.
- **Customizable PDF Output**: Allows specifying options like page size and margins.
- **Secure**: Endpoints are secured using JSON Web Tokens (JWT).
- **Health Check**: A dedicated endpoint to monitor service availability.
- **Containerized**: Ready to deploy using Docker.

## API Documentation

The API is documented using Swagger and can be accessed at the root URL (`/`) of the service.

### Main Conversion Endpoint

#### `POST /documents/htmltopdf`

This is the core endpoint for converting HTML to PDF. It requires a JWT Bearer token in the `Authorization` header.

**Request Body:**

```json
{
  "fileData": "BASE64_ENCODED_STRING",
  "fileType": "html | zip",
  "reference": "YOUR_UNIQUE_REFERENCE_ID",
  "options": {
    "page-size": "A4",
    "margin-top": "0.75in",
    "margin-right": "0.75in",
    "margin-bottom": "0.75in",
    "margin-left": "0.75in"
  }
}
```

- `fileData`: Base64 encoded string of the HTML content or a `.zip` file.
- `fileType`: `html` for a single file, `zip` for a zip archive of HTML files.
- `reference`: A unique identifier for the request, used for logging.
- `options` (optional): A dictionary of `pdfkit` options to customize the PDF output. If not provided, default margins are `0in` and page size is `A4`.

**Response (Success - 200 OK):**

```json
{
  "data": "BASE64_ENCODED_PDF_OR_ZIP",
  "mimetype": "application/pdf | application/zip"
}
```

- `data`: Base64 encoded string of the resulting PDF or zip file.
- `mimetype`: The MIME type of the returned file.

## Environment Variables

The application requires the following environment variables to be set:

| Variable   | Description                                                                 |
|------------|-----------------------------------------------------------------------------|
| `tokenkey` | The secret key used for JWT encoding and decoding.                          |
| `usc`      | The audience value to be checked in the JWT payload (`aud` claim).          |

## Getting Started

### Prerequisites

- [Docker](https://www.docker.com/get-started) must be installed on your system.

### Build and Run the Service

1.  **Clone the repository:**
    ```sh
    git clone <repository_url>
    cd <repository_directory>
    ```

2.  **Build the Docker image:**
    ```sh
    docker build -t html2pdf-service .
    ```

3.  **Run the Docker container:**
    ```sh
    docker run -d -p 80:80 \
      -e tokenkey='your_super_secret_key' \
      -e usc='your_jwt_audience' \
      --name html2pdf-container \
      html2pdf-service
    ```

The service will be available at `http://localhost:80`.
